# TASC Builder

TASC Builder is the repository foundation for the Techfellah AI Software Company Builder.

## Repository intent

This repository is intentionally scaffolded as a monorepo foundation only. The root workspace configuration is managed in `pyproject.toml`, while individual application and package directories are reserved for future package-level configuration.

## Repository structure

- `apps/` application entrypoints
- `packages/` reusable packages
- `config/` repository-level configuration
- `templates/` project templates
- `examples/` example assets
- `docs/` documentation
- `docker/` Docker assets
- `scripts/` automation scripts
- `tests/` test harness
- `.github/` GitHub automation
